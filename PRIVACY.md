# Политика конфиденциальности / Privacy Policy

**Расширение:** Coub Tweaks (Chrome)
**Дата обновления:** 21 ноября 2026

## Русский

Расширение Coub Tweaks **не собирает, не хранит и не передаёт** персональные данные.

- Настройки расширения хранятся только в браузере пользователя (`chrome.storage.sync`). Своих серверов у расширения нет.
- Нет аналитики, счётчиков, рекламы и отслеживания.
- Расширение работает только на `coub.com` (домен и поддомены). На других сайтах оно не запускается.
- Чтобы показать в шапке настоящий аватар активного канала, расширение обращается к открытому API самого сайта (`/api/v2/channels/<канал>`) — ровно так же, как это делает сам coub.com. Ответ используется один раз на странице и нигде не сохраняется.
- Кнопки «Скачать MP4» и «Слушать MP3» получают ссылку на файл через публичный API coub.com и передают её браузеру для обычного скачивания. Файлы попадают только на компьютер пользователя.
- Расширение не имеет доступа к истории браузера, закладкам, паролям и содержимому других сайтов.

## English

Coub Tweaks **does not collect, store or transmit** any personal data.

- Extension settings are stored locally in the browser (`chrome.storage.sync`) only. There are no developer servers.
- No analytics, no tracking, no ads.
- The extension runs only on `coub.com` (the domain and its subdomains).
- To show the real channel avatar in the header it calls the site's own public endpoint (`/api/v2/channels/<channel>`), exactly like coub.com does. The response is used once per page and is not stored anywhere.
- The MP4/MP3 download buttons build a file URL via coub.com's public API and hand it to the browser for a regular download. Files only go to the user's computer.
- The extension has no access to browsing history, bookmarks, passwords or other sites.
